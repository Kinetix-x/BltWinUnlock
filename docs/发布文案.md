## 3. Release 说明（中 / 英）

### 中文版

```markdown
## 让与 Windows 配对并连接的任何蓝牙设备，成为登录凭据

已配对的蓝牙键盘（或鼠标）连着时，锁屏上多一个默认凭据磁贴：**按一下回车就进桌面**。
设备断开则一个凭据都不提供，锁屏与平时完全一样。默认只解锁，不主动锁屏。

### 这一版

- 首个公开版本
- 支持本地账户与 Microsoft 账户（录入时会自动判断，并用两种账户形式各问 Windows 一次）
- 自包含包：目标机不用装 .NET；`-fd` 瘦包需要 .NET 10 桌面运行时

### 下载哪个

| 文件 | 说明 |
| --- | --- |
| `BtwuByKinetix_vX.Y.Z.zip` | **推荐**。自包含，解压即用，什么都不用装 |
| `BtwuByKinetix_vX.Y.Z-fd.zip` | 瘦包，体积小；目标机需先装 .NET 10 桌面运行时 |

解压后双击 `启动管理面板.cmd` → 最上面的「安装」→ 一次 UAC 完成（先勾设备、再录口令、最后安装）。

### 请注意

安装需要一次管理员权限（凭据提供程序要进 System32 并在 HKLM 注册）。
程序会保管一份能替代你口令的凭据（`cred.bin`，DPAPI 加密、仅 SYSTEM/管理员可读）——
**不要用在多人共用的机器上**。详见仓库 README 的「安全模型」。

本程序以 **GPL-3.0** 发布，源码即本仓库；分发本包时请一并提供源码获取方式。
```

### English

```markdown
## Turn any Bluetooth device paired and connected to Windows into a sign-in credential

While a paired Bluetooth keyboard (or mouse) is connected, the lock screen gains a default credential
tile: **press Enter and you are back on the desktop**. When the device disconnects, no credential is
offered at all and the lock screen looks like stock Windows. It unlocks only — locking stays Windows' job.

### In this release

- First public release
- Local accounts and Microsoft accounts are both supported (detected at enrollment; Windows is asked
  about both account-name forms and whichever it accepts is kept)
- Self-contained package: nothing to install on the target machine; the `-fd` package needs the
  .NET 10 Desktop Runtime

### Which file

| File | Notes |
| --- | --- |
| `BtwuByKinetix_vX.Y.Z.zip` | **Recommended.** Self-contained, extract and run |
| `BtwuByKinetix_vX.Y.Z-fd.zip` | Smaller; requires the .NET 10 Desktop Runtime |

Extract, double-click `启动管理面板.cmd`, then click Install in the top section of the panel — one UAC
prompt covers ticking devices, entering your password and installing.

### Please read

Installing needs one administrator elevation (the provider must live in System32 and be registered
under HKLM). The program stores a credential that can replace your password (`cred.bin`, DPAPI-encrypted,
readable only by SYSTEM/Administrators) — **do not use it on a shared machine**. See the security model
in the README.

Licensed under **GPL-3.0**; the source is this repository. If you redistribute this package, make the
corresponding source available as well.
```
